# shared-diff-rendering Specification

## Purpose

为多个 Pi 插件提供可复用的差异展示能力，使已计算的旧值、新值和上下文能以可靠的宽屏并排或窄屏上下布局呈现，同时维持各消费者各自的业务语义、终端安全和独立安装能力。

## Requirements

### Requirement: 共享组件接受与领域无关的差异展示数据

`pi-components` SHALL 通过公开子路径提供可复用的差异排版能力；消费者 SHALL 能传入已经确定的旧值、新值、上下文及必要的分组或说明，不要求组件了解目标、文件系统或工具执行。组件 MUST 保留输入顺序与增删含义，且 MUST NOT 自行读写目标或文件、执行工具或发起模型请求。

#### Scenario: 新旧行与说明共同展示

- **WHEN** 消费者提供相邻删除、新增、未变化上下文以及一条分组或省略说明
- **THEN** 排版后所有输入内容及其增删/上下文语义均可辨认，说明不会被伪装成新增或删除

#### Scenario: 只有一侧的变化

- **WHEN** 一个差异块仅新增或仅删除若干行
- **THEN** 只在相应一侧显示真实内容，另一侧为空白或等价占位，不生成虚构的旧值或新值

### Requirement: 差异排版适应实际显示宽度

共享组件 SHALL 支持旧值/新值并排和上下排列，并按消费者提供的显示策略及实际可用列宽选择可用布局。并排 MUST 将相关两侧的换行续行对齐，不得丢失文本；终端宽度不足以安全并排时 MUST 回退为可读的上下布局。输出行 MUST 不超过指定的可见列宽。

#### Scenario: 长行与宽字符

- **WHEN** 新旧内容含长行、中文、组合字符、空行或 emoji，在不同宽度下渲染
- **THEN** 续行按真实终端列宽安全换行，两侧使用必要的空占位保持对齐，完整内容均可访问且无行越界

#### Scenario: 缩放与布局切换

- **WHEN** 容器从足够宽缩小到不足以并排，再恢复宽度
- **THEN** 分别采用可容纳的布局并重新计算换行，差异内容、顺序和增删含义不变

#### Scenario: 颜色不是唯一标识

- **WHEN** 主题不提供颜色或终端不显示颜色
- **THEN** 用户仍可依据旧/新列标签、增删标识及上下文区分变化

### Requirement: 差异数据不能执行终端控制指令

差异展示 MUST 将消费者提供的非可信文本作为数据处理，不能让其中的终端控制序列修改终端状态、伪造布局或破坏选区；允许的主题样式 MUST 保持行宽正确且不得泄漏到相邻行或列。

#### Scenario: 内容包含控制序列

- **WHEN** 待展示内容包含 OSC、CSI、非法控制字符或文本中伪造的框线
- **THEN** 指令不会被终端执行，不能使内容冒充可交互控件，其他合法文字仍可阅读

### Requirement: tool-display 迁移保持既有展示契约

`pi-tool-display` 的 edit/write 差异展示 SHALL 使用共享排版实现，同时保持原有视图模式、阈值配置、换行、行号、hunk、折叠展开、主题及已支持输入的行为；已有公开显示提供者接口 MUST 保持兼容。

#### Scenario: 不同模式与边界

- **WHEN** 用户沿用 auto、split 或 unified 配置并在宽、窄及极窄终端查看 edit/write 结果
- **THEN** 默认与显式配置继续按原规则生效，回退、行号、增删、折叠及展开语义不回归

#### Scenario: 其他展示入口

- **WHEN** 既有消费者通过 tool-display 的只读展示提供者获取工具展示
- **THEN** 接口与原工具结果、配置和上下文语义保持兼容，不因抽取而执行额外工具或模型回合

### Requirement: 共享组件可随消费者独立交付

Goal-X 与 tool-display 的独立安装包 SHALL 能解析共享 diff 的可运行实现及类型契约，不依赖另一个插件已安装或开发工作区路径。新增 diff 能力 MUST 保持 `pi-components` 既有 transcript 公共导出与消费者行为兼容。

#### Scenario: 单独安装与合装

- **WHEN** 在隔离目录分别仅安装 Goal-X、仅安装 tool-display，以及合装二者后启动真实 Pi
- **THEN** 每个插件均能加载并展示自身支持的差异，不访问工作区私有路径或依赖另一插件的嵌套依赖

#### Scenario: 既有 transcript 消费者

- **WHEN** 现有 transcript 消费者使用原公开子路径加载和渲染
- **THEN** 既有导出、类型与运行时行为不因新增 diff 子路径而改变
