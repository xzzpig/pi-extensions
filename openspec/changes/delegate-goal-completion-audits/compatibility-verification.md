## 范围收紧记录

- `packages/pi-subagents` 初始仅保留从现有 eject handler 抽取的共享 service、其直接 public export、manifest export 和直接测试。
- 用户审阅真实 Pi 事件后额外批准：仅在 `src/runs/foreground/execution.ts` 将 `message_end`/`toolResult` 与 `tool_result_end` 归一化为同一 bounded progress record，并按 `toolCallId` 去重，及其直接 unit/integration 测试。

- 除上述 exceptions 外，delegation 调度、preflight、MCP、skills、Fleet、mission、slash command、文档及其他 runtime 实现仍不修改。
- 范围外 lint、warning、format 或类似诊断不属于本变更验收范围，明确忽略；不得为了消除它们扩展修改面。
- 原 G-01/S-01/S-02/V-01 等记录发生在范围收紧之前。完成前仅应重新验证 Goal-X 和 eject-service 允许范围，并在该范围内更新结果。

## 记录规则

- 改造前基线只描述 embedded auditor 的事实，不代表改造后的期望。
- 改造后每项至少映射到一个已执行测试；测试名称、此记录或两者均引用对应 ID。
- loader-based child 执行、Fleet 状态和 widget 渲染均可自动化，因此不以人工观察取代自动化断言。
- 本机缺少 real Pi-session E2E 所需的 runtime package；该 suite 的一个场景被框架跳过，但不作为任何条目的唯一证据。
