# Proposal

## Why

Starline 模型药丸目前打开自制简化气泡，既不能输入筛选，也不能用滚轮浏览；无模型范围配置时甚至只列出前 8 个候选。用户需要直接使用 Pi 原生模型选择器，并让药丸、`/model` 和快捷键三个入口都支持鼠标操作，且所有改动必须局限于当前插件仓库。

## What Changes

- 模型药丸的点击动作改为调用当前编辑器的原生模型选择动作，保留草稿，不再打开简化模型气泡。
- Starline 加载期间为原生模型选择器提供统一鼠标适配：滚轮浏览筛选后的候选、左键点击可见模型行确认选择。
- 保留原生搜索、模糊匹配、候选刷新、all/scoped 范围切换、键盘导航、默认模型保存与取消语义；不复制原生选择器。
- 按实际渲染行进行命中，覆盖长名称换行、尺寸变化、空结果和候选异步更新，防止误选及滚轮穿透。
- 增加能力探测、明确降级和可逆生命周期清理；点击与滚轮仅依赖 Pi 原生组件 API，不要求安装共享鼠标包；共享包现有指针 API 只提供可选手形增强，不新增公共 API 或全屏鼠标路由。
- 新逻辑、测试及说明放入 fork-only 文件，上游文件仅保留必要接入点。`/starline model` 的既有命令循环语义不在本次调整范围。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `pill-rendering`：增加模型药丸打开原生选择器、安全调用编辑器动作、草稿保留及不可用降级的要求。
- `mouse-api`：增加 Starline 对所有入口的原生模型选择器鼠标适配、准确命中、事件归属与清理要求，不改变共享 API 版本或已有全局路由契约。

## Impact

- 主要涉及 `packages/pi-starline/extensions/starline/` 下的模型药丸动作、编辑器动作访问、选择器适配和生命周期安装/清理，以及 fork-only 测试和文档。
- 复用 Pi 主入口导出的 `ModelSelectorComponent`、编辑器 `app.model.select` 动作和组件级鼠标派发；选择器内部状态仍需要受保护的兼容适配。
- 不修改 Pi 核心、Nix store、全局安装目录或用户配置；不新增强制运行时依赖、不发布、不提交。
- 实现阶段维护 `subtrees/pi-starline.json` 的实际接入点记录，并运行类型检查、回归测试、分歧审计和真实 Pi TUI 验证。
