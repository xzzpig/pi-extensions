# 提案：在目标 Dashboard 保留上次审计失败原因

## Why

完成审计不通过后，结果卡约 6 秒就消失，普通 Dashboard 可能只剩下「所有任务都已完成」，用户看不到目标为什么还没完成。审计报告已经落盘，不应要求用户在结果卡消失前读完，或回聊天记录找原因。

## What Changes

- 保留现有短时审计结果卡；恢复普通 Dashboard 后，在任务区上方常驻显示当前目标最近有效审计的拒绝或运行错误。紧凑视图显示一行摘要，展开视图显示有界报告预览。
- 通过既有 `/goal-status verbose` 查看完整的已记录失败报告；复审运行时继续显示本轮动态清单，不把上一轮结果当成本轮裁决。
- 不新增「正在返工什么」的状态，不改任务勾选、审计协议、完成条件、快捷键或底边框控件，不恢复审计 transcript 面板。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `goal-lifecycle`：补充现有审计结果卡之后的普通 Dashboard 展示，以及完整失败报告的查看方式。

## Impact

仅影响 `packages/pi-goal-x` 的账本读取投影、普通 Dashboard 和状态命令的展示。复用现有审计记录，不改变权威账本格式，不新增命令、依赖或模型调用。
