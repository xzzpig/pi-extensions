# Proposal

## Why

现有美化插件已分别提供思考显隐、工具富输出和编辑器/状态栏美化，但连续工具、思考及插件消息仍占用较长转录。需要独立的组级收纳插件，工作期间保留原展示，整轮真正结束后再折叠，并允许用户配置哪些工具常显、哪些特殊消息随组收纳。

## What Changes

- 新增 `packages/pi-group-collapse`，npm 名称为 `@xzzpig/pi-group-collapse`；参考 pi-tidy 的分组思路，不导入其子树、不依赖或同时加载 pi-tidy。
- 以主会话实际显示顺序建立连续工具、思考及已选特殊消息片段。默认工具入组、特殊消息常显，edit/write 不设默认例外；允许按工具名称、自定义消息类型及普通通知文字前缀覆盖入组选择。不入组的可见内容保持原样并打断组；助手正文、用户消息及原生诊断不因配置被隐藏。
- 配置使用全局 `~/.pi/agent/group-collapse.json` 与项目 `.pi/group-collapse.json`，项目显式提供的规则表替换全局规则表，`/reload` 后统一应用。规则冲突、无效配置、通知来源与后续更新均有确定性处理，不按渲染文本猜测任意组件归属。
- 运行中的整轮保持透传，不因某个工具先完成或中途出现正文而提前做组级折叠。只在 `agent_settled` 且最终结果正常、成员均已静止后，统一折叠本轮片段。
- 异常、中止、截断及无法确认正常完成的轮次保持原样，并记为待收纳；同一会话当前分支后续一轮正常结束时，将已静止的待收纳片段分别折叠，不跨用户消息或轮次合并。
- 完成后的组显示一行摘要，分别统计工具、思考及特殊消息；支持只有特殊消息的组。点击直接恢复整段现有 renderer 的展示，不增加 Tidy 式成员列表，不改成员的原始展开状态。
- 为组摘要提供独立展开对象，并对 pi-starline 的点击目标解析增加一个可选、版本化的显式目标接入点，避免把摘要误判成第一个工具。其余点击、选择、复制和快捷键保留既有行为。
- 对性能与生命周期建立验收约束：不在渲染中持续申请重绘、不轮询、不逐帧重建历史分组或扫描完整结果；会话/分支重建时释放旧视图与索引。
- 实现完成前的最后一道验收必须在隔离环境运行真实 Pi/TUI e2e，并用 asciinema 录制实际测试过程；交付可回放 `.cast`、场景时间点、测试配置与启动命令、版本信息及会话/断言证据，供用户核查。缺少真实运行或有效录制不得宣称最终验收完成。

## Capabilities

### New Capabilities

- `transcript-group-folding`：主会话工具/思考/特殊消息的可配置成员选择、连续片段划分、整轮结束后的自动折叠、异常延后收纳、原样展开、输入兼容与资源生命周期。

### Modified Capabilities

- `mouse-api`：扩展既有点击归属规则，允许宿主组件通过版本化显式目标解析器把组摘要行映射到独立的可折叠组对象；未命中时保持现有 `setExpanded` 解析、思考点击和选择行为。相关要求只在该既有能力域内增改，不新建鼠标能力域。

## Impact

- 实现阶段新增 `packages/pi-group-collapse` 的入口、配置加载与匹配、纯分组状态机、特殊消息/通知来源适配、宿主视图适配器、生命周期控制器、摘要交互及测试，并更新根 `README.md`、`versions.json` 与工作区锁文件；提供配置示例但不创建或改写用户实际配置。
- Pi 核心导入保留为 peer dependency；首版面向交互式主会话，不接管 RPC/JSON/print、pi-btw 或 fleet 的自建转录，不要求安装 pi-mouse-events 才能工作。
- pi-starline 仅允许 fork-only 显式目标适配模块、解析入口最小 seam、fork-only 测试/文档及必要 subtree 元数据维护；遵守 `pi-fork-divergence`。不改变其未安装本插件时的默认体验。
- 不修改 pi-thinking-collapse、pi-tool-display、Pi 核心或工具执行/权限逻辑；不修改用户当前安装、设置或主题。
- 本次仅提交规划产物。包实现、真实 Pi 联合测试、安装、发布、提交与推送均不在本轮执行范围；实现仍需用户另行批准。
