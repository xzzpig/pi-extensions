Round-17 findings and closure (production):
1. Coordination failure revokes reply permission BEFORE the cancel:
   coordinationFailure now calls sidechannel.invalidate("coordination_error") before
   SUBAGENT_DELEGATION_CANCEL_EVENT is emitted, so the cancellation window cannot accept or deliver
   another ask for that attempt.
2. Cancel failure no longer echoes an external exception body: the cancelAttempt catch finishes with
   the fixed text "Could not cancel goal auditor delegation: error details omitted".
3. The session-scope capture fails closed with a fixed diagnostic: ctx.sessionManager.getSessionId()
   is wrapped, and a throw returns {approved:false, disapproved:true, error:"Goal auditor delegation
   failed: error details omitted", requestId} WITHOUT launching any child, so the upper layer can no
   longer splice an external body into "Goal auditor failed unexpectedly".
4. A native ask cancelled while the SDK session is being created no longer starts the model: after
   ensureSession the channel re-checks invalidated/disposed/request.signal.aborted, writes a bounded
   cancelled record, aborts+disposes the late session and returns a cancelled error WITHOUT prompting.
