# 设计：丰富转录分组标题

## Context

`pi-group-collapse` 根据真实可见顺序和规则维护片段，由 `runtime.ts` 按模型修订生成片段统计，`view.ts` 决定摘要宽度，`header-style.ts` 给各标题路径统一着色。分组是否可折叠由独立的生命周期和成员静止证据决定。Pi 提供顶层工具执行事件和助手流式块事件；现有历史投影没有逐思考段和临时通知的起止时间，也不需要它们来重建分组。

## Goals / Non-Goals

- 复用现有成员、衍生索引和标题投影；同一个组在折叠、展开和不同承载组件中使用相同统计。
- 让计时证据独立于谁渲染首行、何时折叠以及是否切换主题、列宽；计时缺失不得成为新的折叠条件。
- 不做轮级计时、工具耗时求和、背景任务或嵌套工具追踪，不写持久化元数据，不启用或依赖 `pi-tidy` 的渲染能力。

## Decisions

### 1. 基于现有片段一次计算标题统计

在现有 `SegmentSummary` 路径汇总精确工具名及调用次数，按次数降序、同次数按名称稳定排序，复用已有失败和通知等级计数。工具名仅在显示层清除 ANSI 与控制、换行等不可用于标题的字符；空名称或不适合显示的名称省略，不改变规则对原名的匹配。时间与名称明细放入现有按修订失效的派生索引，不在每个成员的 render 或命中检测中重扫组。标题所依赖的统计或计时证据改变时失效，但与标题无关的流式增量不触发额外刷新。

采用「先排原标题，再用余量排附加项」而非拼接后整体截断。保留箭头、语义标记、核心计数和可放下的标签；附加项依次保障异常数量、耗时、工具名条目。显示时，「耗时」放在箭头与异常标记之后、核心内容之前；这一顺序不改变列宽分配优先级。核心计数和异常数量均使用「名称×次数」。异常数量可按失败、通知错误、通知警告的顺序逐项让位；工具名按完整条目排版，遇到过长名称可以跳过，避免它屏蔽其他较短名称。用终端列宽度量，记录的耗时用稳定格式而非动画。装饰与点击身份沿用同一行；末尾收起控件不变。

### 2. 观测成员事件，不给分组重新定时

为当前视图使用同一单调时钟记录成员区间。时间只来自可可靠关联的实际事件，不使用组件首次渲染或 `agent_settled` 时间作为起止：

- 顶层工具按调用 ID 配对 `tool_execution_start` 与 `tool_execution_end`；忽略带父调用 ID 的嵌套事件，允许事件先于成员组件绑定。只有真实可用的配对才进入统计，不用结果创建时间倒推起点。
- 思考优先使用助手流式 `thinking_start` 和 `thinking_end` 的 `contentIndex`，将同一条消息内相邻块归并到当前可见思考段的既有身份。只在消息归属和块到段映射可靠时使用；空段、标识不明或事件不完整不能推测时间。
- 可验证的自定义消息出现事件和扩展通知入口提供瞬时点，分别与当前自定义消息或已证明的通知组件身份绑定。对于自定义消息，只对宿主默认 renderer 的有界、可验证数据计时；任意扩展 renderer 可以读消息背后的外部状态，不能凭消息字段相等断言展示内容未变。计时失效本身不展开分组；明确的正文或成员变化仍按既有更新规则处理。复用或替换内容时旧点不能继承给新成员；仅尾行迁移不重置可验证的旧点。无法区分来源、内容代际或真实出现时刻时不使用该时间。

已有分组仍决定实际成员。当全部成员有可靠时间时，取最大结束减最小开始，而非记录分组对象创建到折叠的时间。这样保留组内空档、不重复计算并行，遇到可见边界拆组或异常延期时也不会带入组外成员或跨轮等待。已观测区间不会因点击、终端变宽、会话继续运行而重新计时。无法同时证明全部成员时间时，只省略耗时字段。

### 3. 把计时限制在当前视图生命周期

同一视图中，已绑定成员的计时随现有成员索引保留；未绑定事件仅在可能匹配的当前轮内暂存，轮次结算后清理未匹配记录。成员失效、脱离片段时释放对应引用，重建、卸载或替换视图时清空计时，避免迟到事件污染新视图。同一视图内等待后续正常轮收纳的异常片段可保留其已绑定记录。

相比仿照 `pi-tidy` 写自定义计时条目，内存方案不引入兼容或存储成本。恢复只用原有分组历史投影，不推算时间。也不改会话消息、工具执行或成员 renderer。

## Risks / Trade-offs

- 宿主事件与可见成员映射可能不完整 → 使用已有会话和组件身份边界验证关联，未知时只回退耗时，并覆盖事件先到、多个思考段、通知复用、树导航和旧事件。
- 组大时额外格式化成本可能上升 → 每次派生统计才遍历成员；按终端列宽限制可输出附加项，验证稳定重绘不重复统计、也不启动计时器或申请额外重绘。
- 过窄列宽无法显示新信息 → 保留原摘要可用性和原样透传阈值，不能只为显示 `耗时` 而改变折叠状态。

## Migration Plan

无需迁移。既有配置和会话可直接加载；回退插件版本不会留下新配置或会话字段。
