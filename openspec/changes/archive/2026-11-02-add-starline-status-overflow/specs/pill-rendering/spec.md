# 状态栏溢出增量规格

## ADDED Requirements

### Requirement: 单条内容有界且全文保留

启用溢出治理时，系统 MUST 按终端显示列宽限制每个 pill 的内容，内容包含图标与图标间隔，不包含外侧留白、分隔符及端帽。超长内容 MUST 尾部缩略，默认以 `…` 标记，ASCII 模式以 `...` 标记且计入宽度。系统 MUST 保留安全处理后的发布全文，先应用现有格式转换再缩略，不写回发布方状态。

#### Scenario: 中文和带色文本缩略

- **WHEN** 中文、emoji 或 ANSI 样式文本超过内容上限
- **THEN** 缩略后的显示列宽不超过上限，不切断控制序列或使颜色泄漏至后续区域，pill 外形完整

#### Scenario: 数值格式不丢失全文

- **WHEN** 发布文本为 `MCP: 8 servers connected` 且配置格式为 `value`
- **THEN** 状态栏沿用数值格式，面板仍可读取安全处理后的发布全文，发布方文本不变

### Requirement: 单行布局明确汇总未展示项目

启用溢出治理时，footer MUST 保持最多一行，并仅绘制完整 pill；放不下的有效项目 MUST 进入溢出集合并以 `+N` 汇总。有效项目 MUST 是沿用现有布局、去重、启用及非空规则后的内置或第三方项目。仅文字缩略、用户主动关闭、未纳入布局、空文本的项目 MUST NOT 计入溢出。有效项目 MUST 恰好分属可见或溢出集合，不重复、不遗漏。

#### Scenario: 全部项目放得下

- **WHEN** 所有有效项目连同留白、分隔符、端帽可放入一行
- **THEN** 展示所有项目且不出现 `+0` 或汇总入口

#### Scenario: 内置与第三方项目共同溢出

- **WHEN** 内置项目和第三方项目总宽度超出终端宽度
- **THEN** 放不下的两类项目均进入同一溢出集合，入口数字等于该集合的项目数量，不画半截 pill

#### Scenario: 只有文本被缩略

- **WHEN** 一个长 status 缩略后可完整放入且没有其他项目被移出
- **THEN** 不出现 `+N`，该项全文仍可通过命令及适用的点击入口访问

#### Scenario: 汇总数字位数变化

- **WHEN** 未展示数量从 9 变为 10 或从 99 变为 100
- **THEN** 按实际入口宽度重新分配空间，整行不越界，数字与溢出集合一致

#### Scenario: 终端极窄或没有内容

- **WHEN** 常规汇总 pill 无法放入但有未展示项目
- **THEN** 依次尝试无装饰的 `+N` 与 `+`；宽度为零时绘制空行，所有全文仍可通过命令访问

### Requirement: 保留等级与显示顺序相互独立

系统 MUST 优先保留固定项，其次按保留优先级降序、原显示顺序升序取舍，并按原相对顺序绘制最终项目。固定项超出空间时 MUST 按同样的优先级和原顺序取舍，其余收进溢出。系统 MUST NOT 按文本语义、更新时间自动提升等级，不轮播或随机重排；同一等级内 MUST NOT 为填入较短项目跳过较早且放不下的项目。

#### Scenario: 优先级不改变位置

- **WHEN** 原顺序为 A、B、C，空间只允许保留高优先级 C 和 A
- **THEN** 屏幕显示 A、C，B 进入溢出，不把 C 移到 A 前面

#### Scenario: 同级长项目不被短项目插队

- **WHEN** 同等级 A 比 B 早，A 无法放入剩余空间但 B 可以
- **THEN** A、B 及保留等级顺序中更靠后的项目均进入溢出，不用低等级短项目填补空余宽度

#### Scenario: 固定项过多

- **WHEN** 所有固定项不能与入口同时放入
- **THEN** 固定项按等级取舍，不越界，未展示固定项可通过汇总和命令查看

#### Scenario: 相同输入重复渲染

- **WHEN** 项目、配置和终端尺寸没有变化
- **THEN** 可见项、顺序、溢出计数及点击范围保持一致

### Requirement: 完整状态面板具有统一入口和明确范围

系统 MUST 提供 `/starline statuses`；存在溢出时点击 `+N` MUST 打开同一个面板并定位首个未展示项，命令打开则从顶部开始。面板 MUST 展示参与布局的内置项目及启用的非空第三方项目，逐项标明名称或 key、全文、完整/缩略/未展示状态及动作可用性。主动关闭或未纳入布局的非空第三方状态 MUST 放入默认折叠的非展示分组，不计入溢出，不自动启用；未配置内置项目 MUST NOT 被额外生成。

#### Scenario: 不存在溢出也能查看全文

- **WHEN** 所有项目均已显示且用户执行命令
- **THEN** 面板正常打开并包含各项全文，不依赖汇总入口存在

#### Scenario: 主动关闭与未纳入布局

- **WHEN** 某非空第三方状态配置为 off，或未被显式/通配布局纳入
- **THEN** 仅在面板默认折叠的非展示分组中可查看，不占栏宽、不增加 `+N`、不被自动恢复

#### Scenario: 发布方本身只提供摘要

- **WHEN** 插件仅发布 `3 agents`
- **THEN** 面板将其作为全文，不推算或伪造内部详情，已有动作仍可进入插件自己的管理界面

### Requirement: 面板正文可完整阅读且不抢占主布局

完整状态面板 MUST 使用有界视口，正文按面板宽度换行，纵向溢出可滚动而非永久裁掉。系统 MUST 支持方向键、PageUp/PageDown、Home/End 和 Esc；具备鼠标能力时 MUST 支持滚轮。关闭面板 MUST 恢复编辑器焦点并保留草稿；极小终端 MUST 缩减装饰而非横向越界。无 UI 模式 MUST 安全退出，不调用交互面板或生成模型请求。

#### Scenario: 单条长文本与很多项目

- **WHEN** 一条正文超过屏幕高度或存在 100 个状态
- **THEN** 用户仅使用键盘即可滚动读完所有正文，面板不无限增高，不改变主对话布局

#### Scenario: 方向键滚动而不改变选中项

- **WHEN** 面板打开且选中第三条，用户按 ↓
- **THEN** 视口下移一行而选中项仍是第三条；只有 Shift+↓ 才把选中项切到下一条，Home/End 才跳首尾

#### Scenario: 极窄终端仍可读到正文

- **WHEN** 面板宽度只有 1–2 列
- **THEN** 去掉正文缩进与边框后逐行显示正文，连续滚动可看到发布内容的每个字符，不存在只有装饰的空白屏

#### Scenario: 关闭和无 UI 降级

- **WHEN** 用户关闭面板或在无 UI 模式触发命令
- **THEN** 前者恢复草稿与焦点，后者不打开交互面板、不抛出破坏会话的异常且不发送模型请求

### Requirement: 全文入口不得覆盖原点击动作

已有动作的 pill MUST 继续运行原动作；无动作且缩略的 pill MUST 打开面板并定位自身；无动作且完整显示的 pill MUST 保持只读。面板仅在用户明确按 Enter 或选择操作入口时运行原动作，浏览、悬停和滚动 MUST NOT 执行动作。执行前 MUST 重新按 key 查询有效动作并关闭状态面板；无可见锚点的溢出项 MUST 仍可调用原动作，不伪造锚点、不绕过原动作安全检查。

#### Scenario: 已有 MCP 动作与全文入口共存

- **WHEN** MCP pill 已缩略且存在默认 adapter 动作
- **THEN** 点击仍打开 adapter 原面板；全文通过 `/starline statuses` 查看，原 MCP 路由和防重入检查继续生效

#### Scenario: 只读缩略项查看全文

- **WHEN** 无注册动作的缩略项被点击
- **THEN** 面板定位该项，不生成模型消息，不注册或覆盖第三方动作

#### Scenario: 面板显式操作隐藏项目

- **WHEN** 用户在面板对溢出项明确执行原动作
- **THEN** 面板先关闭，再以当前会话和可选空锚点调用一次有效动作；动作消失或失败时安全降级，不破坏渲染循环

### Requirement: 更新与会话生命周期保持状态阅读稳定

状态栏和打开的面板 MUST 随状态、配置、终端尺寸变化刷新，不依赖新增高频轮询。面板 MUST 按稳定 key 保留选择与尽可能保留滚动位置；条目消失时选择相邻条目，不误执行替代条目。会话结束、切换或 reload MUST 关闭面板、清理订阅与旧快照，不允许旧会话动作执行。

#### Scenario: 状态增长与删除

- **WHEN** 阅读过程中某项正文更新或选中条目被删除
- **THEN** 尽可能保持阅读位置，选中条目存在时仍按 key 跟随，删除时移到邻近项，过时输入不会执行新条目动作

#### Scenario: 调整终端尺寸

- **WHEN** 用户缩小或放大终端
- **THEN** 栏布局、溢出计数、点击范围与面板视口同步按当前尺寸更新，不沿用旧列坐标

#### Scenario: 全部状态消失或会话结束

- **WHEN** 全部条目消失或发生会话切换
- **THEN** 前者显示空态，后者关闭面板并释放旧状态，后续操作不引用旧上下文

### Requirement: 溢出配置默认启用且逐字段容错

系统 MUST 提供 `pill.overflow`：`enabled`、`maxContentWidth`、`extensionMaxContentWidth`、`maxWidths`、`priorities`、`pinned`。默认分别为 true、32、28；目录/Git 内容默认上限 24；queue 优先级 100，model/context 为 80，其余为 50，固定列表默认空。宽度覆盖优先于类别默认值。内置 key 沿用 segment key，第三方用 `extensionStatus:<key>`。非法字段 MUST 独立回退，未知 key MUST 保留但未匹配前不生效。

#### Scenario: 部分配置错误

- **WHEN** 用户设置一个非法宽度，同时配置合法优先级与固定项
- **THEN** 仅非法宽度回退默认值，其他配置仍生效，不覆盖未知 key 或无关现有配置

#### Scenario: 默认配置及关闭治理

- **WHEN** 不提供新配置或显式设置 enabled 为 false
- **THEN** 前者启用上述默认策略，后者恢复旧单行布局与原点击行为但仍提供全文命令，面板据实际显示结果标记未展示/缩略

#### Scenario: 日常设置入口

- **WHEN** 用户通过 `/starline` 调整设置
- **THEN** 可设置溢出开关、第三方默认上限、当前 status 的优先级与固定项，并能进入完整状态面板；高级逐项宽度可通过 JSON 配置

### Requirement: 全文展示遵循安全与兼容契约

系统 MUST 从发布快照生成安全正文，过滤光标移动、清屏和危险控制字符，不直接执行原始控制序列。完整指安全处理后的发布内容，不包含未发布内部数据。系统 MUST 保持原始色/主题色、数值格式、图标及公开 pill API；新增入口 MUST 不占用第三方注册 key，不要求发布方或可选鼠标包配合才能通过键盘阅读全文。

#### Scenario: 恶意控制字符与原始色

- **WHEN** 发布内容包含合法 SGR 和清屏/光标控制序列，且使用 original 色模式
- **THEN** 合法样式按原有安全规则保留、危险序列不生效，正文可阅读且不污染相邻区域

#### Scenario: 无鼠标包和注册名冲突

- **WHEN** 未安装可选鼠标包，或第三方发布与内部入口名称相似的 status
- **THEN** 命令与键盘操作仍可用，内部入口不覆盖、删除或误调用第三方注册，公开锚点协议不变

## MODIFIED Requirements

### Requirement: 覆盖范围与不得改变的既有行为

该对比色 MUST 同时作用于 pill 正文、相邻同背景 pill 之间以文字色绘制的细分隔符，以及复用同一选择逻辑的 pill 气泡正文。系统 MUST NOT 因对比色逻辑改变 pill 背景色解析、`colorSources` 的主题/终端来源、`extensionStatuses` 的默认色与逐项颜色、图标或 pill API 契约。启用溢出治理时，允许按本规格的单条缩略、完整项目取舍和汇总规则改变宽度与点击热区；保留项目的分隔符样式不变，热区 MUST 与实际绘制结果一致。关闭治理时保持旧布局。

#### Scenario: 同背景相邻 pill 的细分隔符

- **WHEN** 相邻两个 pill 解析出相同背景
- **THEN** 两者之间绘制的细分隔符使用与正文相同的对比色，箭头与几何位置不变

#### Scenario: 气泡正文与 pill 正文一致

- **WHEN** 某个 pill 被点击打开气泡
- **THEN** 气泡选中行使用与 pill 正文相同的对比色取值（终端自有背景见下一条要求）

#### Scenario: 除文字色外渲染结果不变

- **WHEN** 同一组 pill 输入在相同溢出配置和终端宽度下，仅切换对比文字色实现进行渲染
- **THEN** 背景 SGR、分隔符、圆角、可见宽度与点击热区完全一致，差异仅限文字前景色

### Requirement: MCP 状态沿用发布者的显示内容

Starline MUST 将第三方状态 key `mcp` 按既有第三方 status 路径渲染为 pill，继续尊重用户的显示、顺序与配色配置。MCP 适配 MUST NOT 重写发布者文本、解析或自行推算连接数量、另建重复 MCP pill，也 MUST NOT 读取或修改 adapter 配置文件。简短格式由 adapter 的 `compact` 设置提供。启用溢出治理时，MCP 与其他 status 一样遵守内容宽度上限和整体取舍规则，发布全文 MUST 可在完整状态面板访问，不能用截断后的摘要替代保存的全文。

#### Scenario: 简短计数原样显示

- **WHEN** adapter 发布 `mcp = "MCP 0/1"`，且该状态可见、使用默认全文格式并能放入内容宽度上限
- **THEN** pill 显示 `MCP 0/1`，并保留已连接数与已启用数的不同含义，不因零连接额外添加故障标记

#### Scenario: 特殊提示不被适配裁剪

- **WHEN** adapter 发布连接中、项目信任阻止或后台任务等提示，且用户没有配置额外文本变换
- **THEN** Starline 沿用既有安全清洗显示该提示；启用溢出治理时可缩略或收进汇总，但全文在面板可读；关闭治理时沿用旧终端宽度截断规则，不将其替换为固定计数

#### Scenario: 隐藏与清空状态

- **WHEN** 用户隐藏 `mcp`、将其移出 pill 布局且不再通配展开，或 adapter 清空该状态
- **THEN** 不存在该 pill 的可见点击热区，适配不得自行恢复或新增一个 MCP pill
