# 目标确认鼠标交互与共享差异展示

## Why

`/goal` 创建确认与 `/goal-tweak` 调整确认目前主要依赖键盘；长提案不易在弹窗中浏览，且调整确认框限制为 80 列，即使终端宽阔也只能上下显示差异。用户需要安全、可预期的鼠标确认与更易比较的宽屏新旧对照，同时避免在两个插件中维护相互漂移的 diff 渲染实现。

## What Changes

- 为普通目标创建与既有目标调整的**最终确认框**接入 Pi 原生组件鼠标事件：滚轮浏览内容、点击决策行只选中，再用明确的独立确认控件或原有键盘确认执行；默认高亮项可直接通过独立控件确认。审计开关、差异/全文切换及反馈编辑器可按各自语义操作，拖选、双击、链接和失效手势不能误执行决策。
- 两个确认框在空间足够时让正文滚动而决策区尽量固定；极矮屏保留全部内容与操作的可达降级。创建框不再因有限高度而让弹窗中的正文中段不可浏览。
- 调整确认框的**实际可用内容区**至少 120 列时以旧值/新值并排展示所有适合配对的语义差异；较窄时使用原有上下排列。正文、验证契约、按任务 ID 匹配的任务变更和设置均保持原意，颜色不是唯一标识；全文视图及历史结果记录保留原语义。
- 将 `pi-tool-display` 现有 diff 的通用排版能力提取至 `pi-components` 的公共子路径，Goal-X 与 tool-display 使用同一共享实现；保留 tool-display 原有布局配置、效果和安全边界。Goal-X 自己负责有效候选及领域语义，不把任务变更当普通文件 diff 重新猜测。
- 保留目标事务、并发失效检查、键盘快捷键、反馈草稿、审计选择、基础 UI/无 UI 回退以及已有任务树与审计面板交互；本变更不新增点击停止审计、逐项接受差异、持久化 UI 状态或强制安装其他 Pi 扩展。

## Capabilities

### New Capabilities

- `shared-diff-rendering`: `pi-components` 面向多个插件提供有界、宽度自适应的通用差异排版能力，以及消费者迁移与独立打包兼容契约。现有 `transcript-builder-api` 专属会话 transcript，不覆盖通用 diff；仓库目前没有同域 capability。

### Modified Capabilities

- `goal-lifecycle`: 扩展目标创建/调整最终确认的鼠标和可达视口行为，并修改默认语义差异展示规则以支持宽屏并排；保留权威候选、历史快照与生命周期事务要求。

## Impact

- `packages/pi-goal-x`：创建最终确认入口、fork-only tweak 确认与语义展示适配、组件测试与用户说明；优先 fork-only 模块和上游文件最小接缝。不得覆盖已完成但尚未归档的任务树与审计面板鼠标工作树。
- `packages/pi-components`：新增 diff 公共子路径及类型、渲染测试和打包说明；现有 transcript 导出与消费者保持兼容。
- `packages/pi-tool-display`：迁移其现有 diff 排版调用至共享实现；以回归测试证明原有配置、输出与包行为，遵守其 subtree fork 分歧纪律。
- 两个可独立安装插件均需包含或可靠解析共享组件的可运行产物；私有工作区库不能假定已全局安装或由另一个插件提供。按需更新相关包清单、lockfile、打包脚本、仓库发布门禁及其直接测试，并执行 tarball 验收；Goal-X 原来禁止仅为已移除 auditor transcript 引入该库的契约仍须保留，不能借此恢复该功能。
- 不修改 Pi 核心、鼠标共享扩展或其他插件的业务逻辑，不调整目标工具 schema、目标存储版本或审计协议；不自动提交、推送、发布或归档 OpenSpec 变更。
