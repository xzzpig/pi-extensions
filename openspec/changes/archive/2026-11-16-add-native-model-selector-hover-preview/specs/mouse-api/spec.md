# 规格增量

## ADDED Requirements

### Requirement: 模型行提供独立的视觉悬停提示

原生模型选择器收到无按键移动事件且指针命中当前可见模型时，系统 SHALL 为该模型的实际渲染行显示背景提示，包含换行续行。悬停样式 MUST 与原生待确认候选标记可区分，保留原生箭头、当前模型和默认模型标记，并在深浅主题下可辨识。该行为 MUST 对模型药丸、`/model` 和模型选择快捷键入口一致。

#### Scenario: 悬停换行模型

- **WHEN** 指针移到一个可见模型的名称或提供方换行续行
- **THEN** 同一模型的各渲染行出现悬停背景，不高亮相邻模型、说明或计数行

#### Scenario: 悬停目标切换

- **WHEN** 指针从模型 A 移到模型 B
- **THEN** 背景提示从 A 转到 B，只保留一个悬停目标；原生标记和文本不丢失

#### Scenario: 三种入口与主题

- **WHEN** 用户在深色或浅色主题下分别通过药丸、命令和快捷键打开选择器并悬停
- **THEN** 提示语义一致，文字及原生待确认标记仍可辨识，不增加或挤走渲染行

### Requirement: 悬停不改变原生确认语义

悬停 MUST 只改变视觉提示，MUST NOT 改变键盘或滚轮的待确认候选、原生详情、可见窗口、默认模型或实际会话模型，也 MUST NOT 触发消息或模型请求。Enter 和保存默认模型 MUST 仍针对原生待确认候选；有效左键完整点击 MUST 仍按实际点击目标确认一次。

#### Scenario: 悬停与 Enter 分离

- **WHEN** 键盘／滚轮待确认候选为 A，鼠标悬停 B 后按 Enter
- **THEN** 原生流程确认 A 而非 B，不因悬停改变目标

#### Scenario: 保存默认与点击分离

- **WHEN** 原生待确认候选为 A 而鼠标悬停 B，用户使用保存默认模型动作
- **THEN** 保存目标仍为 A；若用户改为有效左键完整点击 B，则只确认 B 一次

#### Scenario: 列表边缘连续悬停

- **WHEN** 候选超过一屏且用户反复悬停当前可见列表边缘的模型
- **THEN** 不发生视窗跟随、自动滚动或原生详情改变，不确认模型、不发送消息

### Requirement: 悬停状态只依据可验证的组件事件与布局

系统 MUST 仅按组件收到的事件和当前可验证布局维护提示，不按显示文字猜测模型身份。组件收到非模型位置的移动时 MUST 清除提示；移出整个选择器且未收到组件事件时 SHALL 保留最后提示，不新增外部输入监听。搜索、范围切换、候选刷新、键盘导航、滚轮或尺寸变化时 MUST 清除旧提示，直到新的有效移动事件建立目标。

#### Scenario: 移到组件内非模型区域

- **WHEN** 已有悬停提示，组件随后收到位于搜索框、说明、边框或空白区域的移动事件
- **THEN** 旧悬停提示被清除，不改变键盘焦点或确认模型

#### Scenario: 移出整个选择器且没有组件事件

- **WHEN** 指针离开选择器且组件未收到后续事件，候选与布局也未变化
- **THEN** 最后提示保留，不为检测离开新增终端输入监听或全屏鼠标路由

#### Scenario: 候选与布局失效

- **WHEN** 悬停后发生搜索、范围切换、刷新、方向键／分页导航、滚轮或终端尺寸变化
- **THEN** 旧提示清除，不自动转移给同位置新候选；新的有效移动才重新建立提示

#### Scenario: 拖拽不是悬停

- **WHEN** 用户按下、拖拽、右击或释放鼠标，而非无按键移动
- **THEN** 不由这些动作建立新悬停目标，不绕过既有同格点击与手势身份校验

### Requirement: 悬停增强保持兼容与生命周期隔离

悬停提示 MUST 不依赖共享鼠标包，旧版缺少指针方法时仅省略手形。绘制 MUST 保持文本、可见宽度、行数及非目标行样式，MUST NOT 产生跨行背景泄漏。关闭、会话结束、reload 和卸载 MUST 清理自身提示与状态，保留补丁所有权契约，不影响其他选择器。必要几何不可验证时 MUST 清除旧提示并沿用去重说明，不静默保留错误提示。

#### Scenario: 三种共享包状态

- **WHEN** 共享包未加载、旧版缺少指针方法或已提供指针方法
- **THEN** 有效组件移动均可触发相同的视觉提示，仅可选手形效果不同，不重复处理点击和滚轮

#### Scenario: 清理与其他界面

- **WHEN** 选择器关闭、会话结束或 reload 后再次打开模型或设置选择器
- **THEN** 无旧悬停残留、无重复处理或包装链累积，设置选择器不出现本增强

#### Scenario: 几何失效

- **WHEN** 基本候选状态合法但实际模型行几何无法验证
- **THEN** 不显示旧或猜测的悬停提示，按会话去重说明必要能力失败，原生搜索和键盘继续可用

### Requirement: 悬停遵循宿主移动上报边界

系统 MUST 沿用宿主与终端的鼠标上报策略，不为本增强强制开启全移动模式。不提供无按键移动事件时 MUST 保持原生点击、滚轮和键盘功能；验证结果 MUST 区分合成移动事件的组件／TUI 验证与真实终端鼠标移动观察，不以其中一项冒充另一项。

#### Scenario: 复用器未上报无按键移动

- **WHEN** 宿主在 tmux 等环境仅启用按键移动，组件没有收到无按键移动事件
- **THEN** 不伪造悬停、不修改宿主上报模式，其余已支持交互正常；文档说明没有悬停反馈的原因

#### Scenario: 支持移动的运行环境

- **WHEN** 宿主确实向组件派发无按键移动事件
- **THEN** 模型行出现视觉提示，不要求安装共享包；验收记录实际采用的终端及事件来源
