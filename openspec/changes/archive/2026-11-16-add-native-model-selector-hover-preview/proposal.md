# 提案

## Why

原生模型选择器已经支持搜索、滚轮和点击，但鼠标移到模型行上时只有可选手形，没有旧气泡的行高亮反馈。补充仅视觉悬停提示，让用户在点击前看清目标，同时保留已经确认的键盘／滚轮选择和 Enter 语义，避免列表随悬停跳动。

## What Changes

- 模型行悬停增加主题适配的背景提示，覆盖同一模型的换行续行，保留原生箭头、当前模型和默认模型标记。
- 悬停不改变原生选中索引、可见窗口或详情，不确认模型；Enter 和默认模型保存仍针对键盘／滚轮候选，点击仍针对实际点击目标。
- 指针进入其他模型行时更新提示，组件收到移到非模型区域的事件时清除提示；移出整个选择器且组件未收到事件时保留最后提示，不增加输入监听。搜索、范围切换、候选刷新、滚轮、键盘导航、尺寸变化和关闭／reload 时清理失效状态。
- 模型药丸、`/model` 和模型选择快捷键共用增强；不依赖共享鼠标包，手形仍复用既有可选 API。
- 不修改宿主鼠标上报策略；终端／复用器不提供无按键移动事件时不伪造悬停，也不以点击成功冒充真实悬停验证。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `mouse-api`：新增模型列表仅视觉悬停提示、与原生确认状态隔离、动态失效清理及观察边界的要求；不改写已有共享鼠标层契约。

## Impact

- 基于工作区已完成但尚未归档的 `enhance-native-model-selector-mouse`，复用其 fork-only 鼠标适配与几何边界；本变更独立记录增量，不重写上一变更任务或自动同步主规格。
- 预计涉及 `packages/pi-starline/extensions/starline/fork-model-selector-*.ts`、fork-only 测试和说明。只使用现有组件派发，不增加终端输入监听、组件外观察或全屏路由补丁。
- 不复制选择器，不改 Pi 核心、安装目录或用户全局配置，不新增共享公共 API、强制依赖、配置开关或发布动作。
- 实施前验证原生渲染组合、ANSI 背景恢复、组件事件边界和真实类契约；再执行类型、全量测试、分歧审计、定向格式与隔离 TUI 录屏验证。深浅主题和终端移动事件上报限制须明确记录。
