# 规格场景证据索引

测试命令与环境见 `implementation-notes.md`。`fork-task-tree-view.test.ts` 简写 V、`fork-task-widget.test.ts` 简写 W、`fork-task-mouse.test.ts` 简写 M、`fork-mouse-capability.test.ts` 简写 C；原 `goal-dashboard-model.test.ts` 简写 D。TUI 录像及脚本化实际屏幕断言用 **单包**（`run-27zvSd`）、**合装**（`run-9Hx5ZV`）、**浮层**（`run-HBncjq`）表示；均是注入终端鼠标事件，而非人工鼠标。审计与结果卡由 fixture 设置，为 UI 回归而非真实审计裁决。

| 规格场景                   | 已执行证据与观察                                                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 执行后部深层任务           | V 深层焦点、W 不同宽度长中文、单包初始 child 实际行                                                                          |
| 当前任务是父任务           | V 当前父节点展开一层、W 父任务单击                                                                                           |
| 无有效显式任务焦点         | D `invalid currentTaskId falls back...`；V 推断焦点变化                                                                      |
| 已无待办任务或任务禁用     | W 叶子和没有焦点；D disabled/empty 模型用例                                                                                  |
| 未完成任务直接切换执行焦点 | V 手动浏览后焦点变化；单包 `/fixture-next`，t23 行实际可见                                                                   |
| 跨分支执行                 | V 深层投影及焦点变化；单包 child → t23 → child                                                                               |
| 列表超出可用空间           | W 矮屏、多宽度；单包 resize 80×24 后 child 可见                                                                              |
| 终端无法容纳任务行         | W 可容纳一行/无法容纳提示（10、12 行）                                                                                       |
| 没有当前任务               | V 当前父节点与最近完成祖先；W 完成叶子                                                                                       |
| 手动查看其他任务           | V 手动浏览保持；W 滚轮；单包滚轮并恢复                                                                                       |
| 手动收起当前路径           | V 手动收起；单包父行点击后 Current child 摘要保留                                                                            |
| 恢复跟随                   | W 控件操作；单包点击 `[回到当前]` 后 child 行恢复                                                                            |
| 模式切换与结构变化         | V 移动/删除；W 模式切换、缩放旧手势                                                                                          |
| 会话替换和重载             | V 不同 goal 状态隔离；M 清除/签名失效；fixture 单包/合装独立新会话启动                                                       |
| 正反向滚动                 | M 正负 delta；W 滚轮和旧 widget 键盘 Home/End/Page 回归；单包/合装滚轮向上                                                   |
| 边界不穿透                 | M 零 delta/区域消费；单包边界录像 `run-tomHjt` 中存在 `! seq 1 120` 长聊天记录，滚到 t0 后继续上滚；前后完整屏幕 `diff` 相同 |
| 非任务区域与浮层           | W 非任务区域不消费；浮层录像点击覆盖位置，父分支不变                                                                         |
| 点击标题或展开标记         | W 父任务行；单包/合装实际单击父行一次收起                                                                                    |
| 拖选和非单击               | M 拖动、右键、双击；单包拖动后仍展开，OSC52 解码 `17  任务 17`                                                               |
| 叶子或非任务行             | W 叶子不触发；M 未命中不触发                                                                                                 |
| 控件操作                   | W 覆盖首尾、分隔空白和裁切；单包 `run-7OVMr4` 与合装 `run-ZyGC12` 复核按钮可见边界                                           |
| 缩放与裁切                 | W 缩放旧手势、矮屏、40/70/110 宽；单包 resize 80×24                                                                          |
| 手势期间布局变化           | M 签名变化；W 更换标题、缩放后旧点击不生效                                                                                   |
| 不安装共享鼠标包           | 单包录像仅通过 fixture 安装 Goal-X，实际鼠标点击、滚轮生效                                                                   |
| 鼠标不可用                 | C 普通模式通知去重；V/W 不依赖鼠标的自动跟随和旧 widget 键盘回归                                                             |
| 审计与结果卡保持原状       | W 审计视图旧手势无效；合装模拟审计返回；浮层录像模拟 APPROVED 结果卡及恢复                                                   |
| 查看不写入执行数据         | W 对 goal 结构完整快照进行浏览前后比较；鼠标 helper 不持有 ledger/model 接口                                                 |

原 dashboard/widget/audit 聚焦回归 148 项通过，最终完整单元 1722 项通过；审计反馈修复与完整门禁见实施记录。极小屏与鼠标事件只能确认本机测试的输入与输出，不推断其他终端是否会上报鼠标。
