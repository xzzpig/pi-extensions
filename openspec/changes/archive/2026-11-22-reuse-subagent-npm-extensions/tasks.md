- [x] 1.1 以规格审查现有未批准的实现草稿，并在共用子会话启动入口完成兼容安装复用。用真实 SDK 的本地夹具验证前后台均可复用，无版本、精确版本及兼容范围命中持久目录，不匹配与 dist-tag 保留原始临时来源；普通 npm 包不会被误当作本地扩展。
