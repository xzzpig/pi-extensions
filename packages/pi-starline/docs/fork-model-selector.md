# 原生模型选择器适配

## API 分层

模型选择器的点击、拖拽识别、滚轮及重绘使用 Pi 自身的组件鼠标 API，不依赖 `pi-mouse-events`。共享包只通过既有的可选 `requestPointerShape` 提供悬停手形；未安装、版本不匹配或旧版缺少此方法时仅省略手形，不影响点击和滚轮。终端或 tmux 不报告悬停时也不影响核心交互。

不增加共享鼠标公共 API，不接管全屏鼠标路由，不修改 Pi 安装目录。其他依赖共享鼠标层的全局增强仍遵守它们自己的依赖与降级规则。

## 模型药丸入口

点击模型药丸会调用当前编辑器的原生模型选择动作，打开与 `/model` 或模型选择快捷键相同的界面，不再展示前 8 项简化气泡。搜索和范围切换沿用 Pi 原生行为；取消后草稿保留，浏览不会发送用户消息或发起模型请求。`/starline model` 仍按原有方式循环模型。

选择器或其他界面占用焦点/浮层时，不重复挂载。当前编辑器未提供模型选择动作时给出一次说明，不猜测快捷键、不提交 `/model` 文本，用户仍可直接使用原生命令。包装编辑器必须正确转发动作表；入口读取包装器及其原始编辑器，而不创建新的编辑器。

## 鼠标与键盘操作

通过药丸、`/model` 或原生模型选择快捷键打开时，使用同一套组件鼠标适配：

- 滚轮按 Pi 提供的方向和步长移动当前筛选结果的高亮，原生视窗随之更新；首尾停止、不循环，空结果与边界也不会滚动背后会话。
- 左键完整点击模型行（包括换行续行）沿用原生确认流程；仅浏览或滚动不会更换会话模型。右键、悬停、拖动、搜索框、边框和提示行不确认模型。
- 搜索、all/scoped 切换、方向键、Enter、保存默认模型与 Esc 均沿用原生键盘行为；悬停不会抢走键盘高亮。
- 按下后候选或布局变化时旧点击不确认新目标，需要重新点击。
- Pi 必要能力缺失或原生选择器内部结构不兼容时按会话说明一次；共享指针缺失不告警。清理和 reload 恢复方法的原有自有/继承状态，旧清理不覆盖后续拥有者。

适配模块 `fork-model-selector-mouse.ts` 仅包装模型选择器的组件方法，使用独立的原型所有权记录和弱引用实例状态；无全屏路由补丁或额外终端输入解析。安装顺序为原生鼠标适配在内、选择器边框包装在外，清理必须逆序：先移除边框，再释放鼠标适配。反过来会让边框恢复到已停用的鼠标 render 包装，造成包装链残留。`test/fork-model-selector-lifecycle.test.ts` 通过真实 Starline 会话和两个实际补丁的重复组合周期验证方法及自有/继承描述符恢复。

## 悬停背景

`add-native-model-selector-hover-preview` 约定使用模型行背景作为鼠标位置提示，与原生箭头指示的待确认候选分离。鼠标悬停 B 而原生候选为 A 时，Enter 和保存默认模型仍针对 A；只有有效完整点击 B 才确认 B。悬停不调用原生列表更新、不移动视窗或改变详情，换行续行属于同一模型。

只接收组件事件：移到组件内搜索框、说明、边框等非模型区域时清除背景；移出整个选择器且组件没有收到事件时可保留最后提示，不另加输入监听。搜索、范围切换、同结果刷新、键盘导航、滚轮和尺寸变化使旧背景失效，新的有效移动事件才建立新提示；普通重绘不使有效提示闪失。

行背景装饰保留原生文本、箭头、当前／默认标记、前景样式、行数与可见宽度，并在内部 ANSI 重置后恢复背景、行尾恢复默认背景，避免污染其他行。深浅主题分别验证。装饰与内容代次的契约测试位于 `test/fork-model-selector-hover-render.test.ts`，组件交互测试位于 `test/fork-model-selector-hover.test.ts`；真实 TUI 和终端观察范围以本增量 verification 记录为准。

Pi 1.5.2 在 tmux 等复用器中默认只启用按键移动，不一定上报无按键悬停；本增强不强制切换终端鼠标模式。不收到 move 时没有背景提示，不代表必须安装共享包，点击／滚轮仍可用。注入 SGR move 的真实 TUI 验证与物理鼠标观察必须分开记录；未观察物理鼠标时不得宣称已验证，应提供支持全移动上报的直连终端复验命令。

## 受保护的兼容边界

`fork-model-selector-geometry.ts` 集中读取原生组件的必要内部字段，并在读取前检查结构：

- `filteredModels` 中模型的提供方与 ID，以及合法 `selectedIndex`；
- 原生列表容器与组件子列表、搜索输入和范围状态；
- 原生更新、确认方法、关闭状态，以及组件关联 TUI 的有效终端行数。

这不是 Pi 对内部字段稳定性的承诺。结构不再满足契约时调用方必须明确关闭对应适配，不能猜测模型身份、解析显示文字或让未知行确认模型。即使基本字段合法，列表子组件不足或模型渲染零行导致几何无法验证时，也必须明确告警并按会话去重；事件到达后新发现几何失败同样不能静默退出。未绘制、已关闭或零宽度不视为兼容错误。

行命中从真实子组件渲染高度计算列表起点，再逐个累加可见模型的实际高度，包含名称、提供方信息换行产生的续行。不假设固定标题行数或一模型一行。提示、计数、搜索框和列表说明没有模型目标。

当前可见切片起点复用 Pi 的窗口规则（最多 10 项，选中项附近居中），这是刻意集中维护的内部算法镜像，未来同步需与宿主 `updateList` 对照。几何签名包含渲染宽度、组件高度、宿主终端行数、范围、搜索文本、候选身份和行区间，用于在布局或候选变化后拒绝旧手势。

## 契约验证

仓库依赖当前为 Pi 1.1.0；几何契约已分别针对该版本和真实宿主 Pi 1.5.2 执行，不表示所有 peer 版本都已验证。

```bash
direnv exec . pnpm --filter @xzzpig/pi-starline exec vitest run test/fork-model-selector-geometry.test.ts

# STARLINE_PI_ENTRY 指向待验证宿主公开的 dist/index.js；不更改依赖或锁文件。
direnv exec . env STARLINE_PI_ENTRY=/path/to/pi-coding-agent/dist/index.js \
  pnpm --filter @xzzpig/pi-starline exec vitest run test/fork-model-selector-geometry.test.ts
```

测试使用真实原生选择器和无网络的模型运行时夹具，不复制搜索、刷新或列表渲染。覆盖超过一屏、长行换行、窄宽度、非法坐标、说明行、空搜索结果、清空搜索、候选刷新、范围变化、尺寸变化和关闭后失效。

几何契约测试不等同真实 TUI 验收。最终点击、滚轮、草稿保护及生命周期仍须在隔离 Pi TUI 中录制并验证。
