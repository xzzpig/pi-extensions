# 主模型的新生成目标内容

Goal-X 的新生成主模型内容只提供执行所需的信息，不提供当前上下文 token 数、容量、百分比或 unavailable 占位，也不提供累计耗时、无有效 lifetime token budget 时的累计消费，以及插件附加的审计成本/token/回合统计。

用户明确配置的 lifetime token budget 仍是跨回合消费限额，而不是上下文容量；有效预算总额/已用/剩余读数、有限运行额度、零额度关闭续跑、任务/验收状态、等待条件、阻塞、审计原文及压缩恢复信息保留。

## 旧会话边界

只精简新生成内容，不处理会话中已经持久化的旧目标消息、旧工具返回或旧压缩摘要。它们允许继续随历史重放遥测和当时的预算读数；混有旧历史的整个请求不保证完全没有遥测。新会话不会由本插件新生成这些被排除的统计，同一旧会话里的新内容也遵循精简边界。

新的 get_goal 历史查询在构造返回前选择执行事件/字段，不改变原始账本；已经存在于 session 的旧查询页不解析、不清洗、不重组 cursor 链。

## 不变的内容

dashboard、goal 文件、session/ledger 原始记录、宿主内部 usage 记账以及独立 auditor/Oracle 输入保持原语义。工具 UI 卡片从完整 details 恢复累计统计，而模型 content 使用精简视图。用户 objective、任务 evidence、审计报告和第三方消息中的相似字样不做全局清洗；模型主动读原始文件仍可能看到统计。

不新增设置、命令、上下文阈值、停止策略或数据迁移。重载扩展即可改变后续生成内容，不修改此前记录。
