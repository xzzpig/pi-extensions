# 审计面板鼠标浏览

在支持 Pi 原生组件鼠标事件的全屏界面中，审计面板底边框的 `[展开清单]` / `[收起清单]`（窄屏可缩为 `[展开]` / `[收起]`）与面板快捷键使用同一显示状态。可用的快捷键在空间允许时跟在按钮后；中断键是独立提示，不可点击。Pi 的搜索或对话框占用键盘时，暂停显示面板快捷键提示。展开后，将鼠标放在检查项、换行依据或诊断输出区域滚动，可浏览完整内容；在首尾或清单为空时滚轮仍由该区域消费，不会滚动聊天。底边框、区域外、前置浮层及链接由宿主处理。

正常左键单击完整控件才切换；为让双击选词优先，单击会在约半秒后确认。拖动选字仍可由宿主复制；右键、双击和过期位置不会触发切换。没有鼠标能力时仍可用既有面板快捷键、方向键、Page Up / Page Down、Home / End 和 Escape。审计进行中的 Escape 仍是原来的挂起/继续流程，鼠标不会中断审计。

浏览状态仅在当前 widget 内存中：同一次审计进度更新与挂起后继续保留位置（依据当前内容约束），新目标或新审计从头开始。浏览、折叠与展开只影响显示，不修改目标、检查项或审计结果。
