# 任务树浏览

目标面板按计划顺序显示任务。默认展开当前任务的祖先路径；当前任务本身有子任务时，也显示其直接子任务。其他分支保持收起。当前任务由现有目标焦点决定；焦点无效时沿用首个待办任务的推断规则，展示不会写入焦点。

用户手动滚动或折叠后，普通刷新保留浏览位置与展开状态。执行焦点切换或使用“回到当前任务”时恢复自动跟随。没有待办任务时，视图定位到最近完成任务所在的可见祖先；找不到时从第一行开始。折叠状态只属于当前组件，不写入目标文件。

鼠标功能依赖宿主全屏模式与终端的鼠标上报。任务区内滚轮浏览任务，单击父任务行切换该分支；拖动文字用于选择，不修改任务。鼠标不可用时仍可使用现有键盘导航和自动跟随。
